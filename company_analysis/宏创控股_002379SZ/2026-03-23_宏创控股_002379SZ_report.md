## 5. 因子2 & 因子3 穿透回报率计算

### 5.1 因子2：粗算穿透回报率

**关键参数**：
- C（归母净利润）= 178.64亿
- D（折旧摊销）= 42.46亿
- E（资本开支）= 53.45亿
- G（维持性投入系数）= 0.56（Capex/D&A中位数）
- 市值 = 3518.40亿

**计算**：
```
OE（业主盈余）= C + D × (1 - G) = 178.64 + 42.46 × 0.44 = 197.32亿
粗算穿透回报率 = OE / 市值 = 197.32 / 3518.40 = 5.61%
```

### 5.2 因子3：精算穿透回报率

**基准可支配结余（AA）**：
- AA_2y（近2年均值）= 82.25亿
- AA_excl（剔除负值）= 167.55亿

**敏感性调整**：
- V1（存货跌价准备）：+0（行业上行周期，风险低）
- V5（资本化利息）：+0（财务费用未披露）
- -V_deduct（关联交易利益输送）：-5亿（保守估计）
- X1（周期性调整）：-20%（强周期，处于周期高位）

**调整后可支配结余**：
```
AA_adj = 167.55 × 0.8 - 5 = 129.04亿
```

**精算穿透回报率**：
```
GG = AA_adj / 市值 = 129.04 / 3518.40 = 3.67%
```

**考虑周期位置修正**：
- 当前处于周期高位（铝价接近高点）
- 周期顶部门槛上调2%
- 修正后 GG_adj = 3.67% - 2% = 1.67%

### 5.3 穿透回报率结论

| 口径 | 回报率 | vs 门槛(3.83%) |
|------|--------|----------------|
| 粗算 | 5.61% | 达标 |
| 精算（基准） | 3.67% | 不达标 |
| 精算（周期修正） | 1.67% | 显著不达标 |

**结论**：粗算达标，但精算不达标。当前估值已充分反映周期高位的乐观预期。

## 9. 结论

### 投资评级：观察

**核心逻辑**：

1. **业务转型成功**：通过635亿元关联并购，宏创控股从单一铝加工商转型为覆盖"铝土矿→氧化铝→电解铝→深加工"的全产业链巨头，电解铝产量占全国14.8%，行业地位显著提升。

2. **护城河存在但面临挑战**：一体化成本优势、规模效应、技术领先构成护城河，但自备电优势因政策变化收窄，护城河强度需重新评估。

3. **估值过高**：当前股价27元，历史分位97.9%，较综合基准价溢价1488%。精算穿透回报率3.67%，考虑周期修正后仅1.67%，显著低于门槛3.83%。

4. **安全边际不足**：当前处于周期高位，估值已充分反映乐观预期，安全边际薄且外推可信度低。

5. **治理瑕疵**：历史披露违规、关联交易频繁、审计师更换，治理风险需关注。

### 建议

- **当前不建议建仓**，等待回调或重组落地后验证
- **关注价位**：15元以下可考虑观察仓位，12元以下可考虑标准仓位
- **持续跟踪**：重组整合进展、铝价走势、电力成本变化
